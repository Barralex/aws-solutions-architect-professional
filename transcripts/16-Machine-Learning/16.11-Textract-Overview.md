# 16.11 - Amazon Textract Overview

## Key Concepts

1. Extrae texto, escritura a mano y datos de documentos escaneados usando ML
2. Soporta: PDF, imágenes, formularios, tablas
3. Ejemplo: sube foto de licencia de conducir → extrae fecha de nacimiento, ID, etc.
4. Casos de uso: servicios financieros (facturas), salud (historiales médicos), sector público (formularios fiscales, pasaportes)
5. Exam tip: "extraer texto/datos de documentos escaneados" → Amazon Textract
