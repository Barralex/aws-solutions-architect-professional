# 17.2 - Amazon CodeGuru

## Dos componentes

| Componente | Qué hace | Cuándo actúa |
|------------|----------|--------------|
| **CodeGuru Reviewer** | Revisión de código automatizada (análisis estático) | En cada push/commit |
| **CodeGuru Profiler** | Recomendaciones de rendimiento en runtime | Pre-prod y producción |

## CodeGuru Reviewer
- Analiza cada commit y señala líneas problemáticas
- Detecta: bugs, memory leaks, vulnerabilidades de seguridad, validación de input, resource leaks
- Usa ML entrenado con miles de repos open source + repos internos de Amazon
- Soporta: Java, Python
- Integración: GitHub, Bitbucket, CodeCommit

## CodeGuru Profiler
- Monitorea comportamiento runtime de la aplicación
- Identifica: código ineficiente, uso excesivo de CPU, anomalías
- Heap summaries para detectar objetos que consumen mucha memoria
- Funciona en AWS y on-premises
- Overhead mínimo en la aplicación

## Exam Tips
- CodeGuru = ML-powered code review + runtime profiling
- Reviewer = estático (código) / Profiler = dinámico (runtime)
- Si ves "automated code review" → CodeGuru Reviewer
- Si ves "runtime performance optimization" → CodeGuru Profiler
