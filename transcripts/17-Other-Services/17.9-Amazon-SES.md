# 17.9 - Amazon SES (Simple Email Service)

## What is it
Fully managed email service — send emails securely, globally, at scale.

## Key Features
- Outgoing AND incoming emails
- Reputation dashboard (opens, bounces, spam reports)
- Email stats: deliveries, bounces, feedback loops, opens
- Security: DKIM and SPF support
- IP options: shared IP, dedicated IP, customer-owned IP
- Access: AWS API or SMTP protocol

## Use Cases
Transactional emails, marketing emails, bulk emails

## Configuration Sets
Customize and analyze email sending events:

| Destination | What you get |
|-------------|-------------|
| Kinesis Data Firehose | Metrics (sends, deliveries, opens, clicks, bounces, complaints) → S3 → Athena |
| SNS | Immediate feedback on bounces and complaints |

### IP Pool Management
- Separate IP pools for different email types
- Example: transactional IPs + marketing IPs = separate reputations
- Protects transactional reputation if marketing gets flagged as spam

## Exam Tips
- SES = managed email at scale
- Configuration Sets → Firehose (analytics) or SNS (immediate alerts)
- IP Pool Management = separate email reputations
