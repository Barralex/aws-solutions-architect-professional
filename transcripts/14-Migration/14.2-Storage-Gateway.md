# 14.2 - AWS Storage Gateway

## Transcript

### Concepto: Nube Híbrida
- Parte de la infra en AWS, parte on-premises
- Razones: migración larga, compliance, estrategia de cargas elásticas
- Problema: ¿cómo exponer datos de S3 on-premises?
- Solución: AWS Storage Gateway = puente entre on-prem y cloud

### Tipos de almacenamiento nativo en AWS
- **Block storage:** EBS, EC2 Instance Store
- **File system:** EFS, FSx
- **Object storage:** S3, Glacier

### Casos de uso de Storage Gateway
- Disaster recovery
- Backup & restore
- Migración a la nube
- Extensión de almacenamiento local (tiered: hot on-prem, cold en cloud)
- Caché local para datos en AWS

---

### 1. S3 File Gateway
- Expone buckets S3 como file shares via **NFS o SMB**
- El File Gateway traduce requests NFS/SMB → HTTPS a S3
- Para la app parece un file share normal, pero por detrás es S3
- **Caché local:** datos más recientes se cachean en el gateway
- Storage classes soportadas: Standard, Standard-IA, One Zone-IA, Intelligent-Tiering
- **NO Glacier directo**, pero sí via Lifecycle Policy
- Cada File Gateway necesita un **IAM Role**
- SMB → integración con **Active Directory** para autenticación

### 2. Volume Gateway
- Block storage via protocolo **iSCSI**, respaldado por S3
- Los volúmenes están respaldados por **EBS Snapshots**
- Dos modos:
  - **Cached volumes:** datos primarios en S3, caché local para acceso rápido
  - **Stored volumes:** datos completos on-prem, backup programado a S3
- Caso de uso: backup de volúmenes on-prem → EBS snapshots en AWS

### 3. Tape Gateway
- Para empresas con backup en **cintas físicas**
- Virtual Tape Library (VTL) respaldada por S3 y Glacier
- Protocolo **iSCSI**
- Compatible con principales proveedores de backup
- Cintas se pueden transicionar a Glacier/Glacier Deep Archive

### Despliegue
- Storage Gateway VM se instala **en el datacenter on-premises**
- Es un appliance virtual que corre en tu infraestructura

---

## Key Concepts
- Storage Gateway = puente on-prem ↔ AWS cloud
- 3 tipos: S3 File Gateway (NFS/SMB), Volume Gateway (iSCSI), Tape Gateway (iSCSI VTL)
- Todos tienen caché local para baja latencia
- S3 File Gateway NO soporta Glacier directo (usar Lifecycle Policy)
- Volume Gateway crea EBS Snapshots para restore en AWS
