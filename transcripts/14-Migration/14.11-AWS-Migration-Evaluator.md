# 14.11 - AWS Migration Evaluator

## Transcript

### Qué es
- Servicio para construir un **business case** basado en datos para migrar a AWS
- Obtener baseline de lo que tu organización corre hoy

### Cómo funciona
1. Instalar Agentless Collector → descubre toda la infra
2. Snapshot de tu footprint on-prem + dependencias
3. Analiza estado actual → define estado objetivo en AWS → plan de migración

### Input (dos formas)
- Agentless Collector (instalar)
- Data Import (template con tus datos)

### Output
- Visión rápida de costos personalizados
- Validar que la migración es cost-effective
- Business case para justificar la migración
- Opcionalmente: guía de expertos AWS

---

## Key Concepts
- Migration Evaluator = business case para migración ($$$ justification)
- Agentless Collector o Data Import
- "¿Vale la plata migrar?" → Migration Evaluator
