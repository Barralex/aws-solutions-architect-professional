# 15.11 - VPC Flow Logs

## Key Concepts

1. Capture IP traffic info at VPC, Subnet, or ENI level
2. Sent to: S3, CloudWatch Logs, Kinesis Data Firehose
3. ACTION field: ACCEPT or REJECT → troubleshoot SG vs NACL issues
4. Inbound ACCEPT + Outbound REJECT = NACL problem (SG is stateful, would auto-allow)
5. Query with Athena (S3) or CloudWatch Logs Insights
6. Architectures: Contributor Insights (top IPs), Metric Filter + Alarm (SSH/RDP spikes), Athena + QuickSight
7. NAT Gateway gotcha: Flow Logs show ACCEPT for inbound public IPs, but NAT GW drops it internally
