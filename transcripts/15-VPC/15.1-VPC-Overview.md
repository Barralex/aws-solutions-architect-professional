# 15.1 - VPC Overview (Fundamentos)

## Transcript

### CIDR
- Bloque de direcciones IP: IP/número
- Ejemplo: 192.168.0.0/26 = 64 IPs (192.168.0.0 a 192.168.0.63)
- Se usa en Security Groups, Route Tables, VPC, Subnets

### IP Privadas (rangos)
- 10.0.0.0/8 (10.0.0.0 - 10.255.255.255) → redes grandes
- 172.16.0.0/12 (172.16.0.0 - 172.31.255.255) → medianas
- 192.168.0.0/16 (192.168.0.0 - 192.168.255.255) → domésticas

### VPC
- Lista de bloques CIDR (solo IP privadas)
- Min /28 (16 IPs), Max /16 (65536 IPs)
- Subnets: subconjunto del CIDR de la VPC
- AWS reserva 4 primeras IPs + última de cada subnet

### Route Tables
- Controlan destino del tráfico de red
- Asociadas a subnets específicas
- Regla más específica (/ más alto) gana

### Internet Gateway (IGW)
- Conecta VPC a internet, HA y escalable
- Subnet pública: ruta 0.0.0.0/0 → IGW + instancia con IPv4 pública
- Subnet privada: accede a internet via NAT Instance o NAT Gateway

### NAT Instance vs NAT Gateway
- NAT Instance: EC2 en subnet pública, barata, no resiliente, deshabilitar source/dest check
- NAT Gateway: managed, HA dentro de 1 AZ, deploy en múltiples AZs para HA completa
- Ambas usan Elastic IP

### NACL vs Security Groups
- NACL: stateless, nivel subnet, allow + deny rules, bloquear IPs
- SG: stateful, nivel instancia, solo allow rules, referenciar otros SGs

### VPC Flow Logs
- Registrar tráfico: nivel VPC, subnet o ENI
- Destino: CloudWatch Logs o S3
- Útil para troubleshooting y detectar ataques

### Bastion Host vs SSM Session Manager
- Bastion: EC2 pública para SSH a instancias privadas (gestión manual)
- SSM: sin SSH, sin bastion, mejor modelo de seguridad

### IPv6
- Todas las IPv6 son públicas
- VPC soporta IPv6 dual-stack
- Subnet pública: ::/0 → IGW
- Subnet privada: ::/0 → Egress-Only Internet Gateway (solo IPv6, como NAT para IPv6)

## Key Concepts
- Todo es repaso de fundamentos
- NACL stateless vs SG stateful
- NAT Instance (barata, manual) vs NAT Gateway (managed, HA)
