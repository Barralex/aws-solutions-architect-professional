# 14.7 - AWS CART (Cloud Adoption Readiness Tool)

## Transcript

### Qué es CART
- Herramienta para desarrollar planes de adopción/migración a la nube
- Transforma la idea de migrar en un plan detallado siguiendo best practices de AWS

### Cómo funciona
- Respondés preguntas en 6 perspectivas:
  1. Business
  2. People
  3. Process
  4. Platform
  5. Operations
  6. Security

### Output
- Gráfico con scorecard de preparación
- Reporte personalizado con nivel de readiness
- Recomendaciones de best practices de AWS

---

## Key Concepts
- CART = cuestionario de readiness para migración
- 6 perspectivas: Business, People, Process, Platform, Operations, Security
- Output = scorecard + recomendaciones
- Nivel alto en el examen, no profundiza mucho
