# 14.6 - AWS DMS (Database Migration Service)

## Transcript

### Qué es DMS
- Migrar bases de datos a AWS de forma rápida y segura
- Resiliente y autorreparable (se recupera de fallos)
- Base de datos origen sigue disponible durante la migración
- Requiere una instancia EC2 que ejecuta el software DMS (tareas de replicación)

### Tipos de migración
- **Homogénea:** mismo motor (Oracle → Oracle)
- **Heterogénea:** distinto motor (SQL Server → Aurora)
- **Replicación continua (CDC):** Change Data Capture

### Fuentes (Sources)
- On-premises/EC2: Oracle, SQL Server, MySQL, MariaDB, PostgreSQL, MongoDB, SAP, DB2
- Azure SQL Database
- Amazon RDS (incluido Aurora)
- Amazon S3
- DocumentDB

### Destinos (Targets)
- On-premises/EC2: Oracle, SQL Server, MySQL, MariaDB, PostgreSQL, SAP
- Amazon RDS (incluido Aurora)
- Amazon Redshift
- Amazon DynamoDB
- Amazon S3
- OpenSearch Service
- Kinesis Data Streams
- DocumentDB

### IMPORTANTE: Solo targets (NO sources)
- Redshift, Kinesis Data Streams, OpenSearch → solo destinos, NO fuentes
- No se puede usar DMS para replicar datos DESDE OpenSearch

### AWS SCT (Schema Conversion Tool)
- Convierte esquema de un motor a otro
- OLTP: SQL Server/Oracle → MySQL/PostgreSQL/Aurora
- OLAP: Teradata/Oracle → Redshift
- NO necesario si mismo motor (ej: PostgreSQL on-prem → RDS PostgreSQL)

### Conectividad
- VPC Peering, VPN (Site-to-Site o Software), Direct Connect

### Tipos de carga
1. **Full Load:** extracción completa única
2. **Full Load + CDC:** carga inicial + replicación continua
3. **CDC only:** solo cambios (stream)

### Notas especiales
- Oracle: soporta TDE con BinaryReader (source), BLOBs con primary key (target)
- OpenSearch: solo como target, no source

### DMS + Snowball (migración masiva)
1. SCT extrae datos on-prem → copia en Snowball Edge
2. Enviar Snowball a AWS → datos van a S3
3. DMS toma datos de S3 → migra al target
4. CDC replica cambios que ocurrieron durante el envío
- Combina velocidad de Snowball + replicación continua de DMS

---

## Key Concepts
- DMS = migración de DB con origen disponible durante migración
- SCT solo cuando cambia el motor de DB
- Redshift, Kinesis, OpenSearch = solo targets
- DMS + Snowball para migraciones masivas (TB de datos)
- CDC para replicación continua
