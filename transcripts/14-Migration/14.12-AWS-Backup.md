# 14.12 - AWS Backup

## Transcript

### Qué es
- Servicio fully managed para administrar y automatizar backups centralizadamente
- Sin scripts custom ni procesos manuales

### Servicios soportados
- EC2, EBS, S3, RDS (todos los motores), Aurora, DynamoDB, DocumentDB, Neptune
- EFS, FSx (Lustre, Windows File Server)
- Storage Gateway (Volume Gateway)

### Features
- **Cross-region backups** (DR)
- **Cross-account backups** (multi-account)
- Point-in-time recovery (servicios compatibles como Aurora)
- Backups on-demand y scheduled
- Tag-based backup policies (ej: solo recursos con tag "production")

### Backup Plans
- Frecuencia: cada 12h, semanal, mensual, cron expression
- Backup Window
- Transición a Cold Storage: nunca, días, semanas, meses, años
- Retention period: siempre, días, semanas, meses, años

### Vault Lock (WORM)
- Write Once Read Many policy
- Backups en el vault NO se pueden borrar
- Ni siquiera el root user puede borrarlos
- Protección contra: borrado accidental, malicioso, alteración de retention period

---

## Key Concepts
- AWS Backup = backup centralizado de todos los servicios
- Backup Plans = frecuencia + retention + cold storage
- Vault Lock = WORM, ni root puede borrar
- Cross-region + cross-account
