# 13.6 S3 Cost Savings

## S3 Storage Classes (de más caro a más barato)

| Clase | Acceso | Caso de uso |
|---|---|---|
| Standard | Siempre | Datos activos |
| Standard-IA | Poco frecuente | Backups recientes |
| One Zone-IA | Poco frecuente | Datos recreables (thumbnails) |
| Intelligent Tiering | Auto | Patrones impredecibles (fee monitoreo) |
| Glacier Instant | Raro | Archivos con recuperación rápida |
| Glacier Flexible | Muy raro | Archivos con recuperación lenta |
| Glacier Deep Archive | Casi nunca | Compliance, retención 7+ años |

## 3 Estrategias de ahorro

1. **Lifecycle Rules** - Transicionar automáticamente entre clases + borrar objetos viejos
2. **Compresión** - Comprimir antes de subir = menos GB = menos plata
3. **Requester Pays** - El que descarga paga la transferencia

## Requester Pays (CLAVE PARA EXAMEN)

- **Storage** → siempre paga el dueño del bucket
- **Transferencia (egress)** → paga el solicitante

### Trampa del cross-account role
- Si el usuario usa un role creado EN TU CUENTA → VOS pagás (request sale de tu cuenta)
- Para que funcione: usuarios deben autenticarse con su propio IAM (user/role en SU cuenta)
- Requiere: S3 Bucket Policy + usuarios autenticados con IAM

### Números reales
- Storage 500GB Standard: ~$11.50/mes
- Egress 25TB (50 clientes x 500GB): ~$2,250/mes
- Con Requester Pays: cada cliente paga ~$45, vos $0 en egress
