🛣️ Paso 2 — VIF: qué tipo de carril elegís

Una vez que el cable físico está conectado, elegís un VIF (Virtual Interface) para decirle a AWS a dónde va el tráfico.

🌐 Public VIF
Vas a endpoints públicos de AWS
→ S3, Glacier
→ EC2 public IPs
→ cualquier URL pública de AWS
🔒 Private VIF
Vas a recursos privados en tu VPC
→ EC2 privadas
→ RDS, ALB
→ recursos con IP privada
🔄 Transit VIF
Vas via Transit Gateway
→ múltiples VPCs
→ VPCs que se hablan
→ máxima escala
