# 15.7 - AWS Site-to-Site VPN

## Key Concepts

1. Site-to-Site VPN basics: Customer Gateway + Virtual Private Gateway + 2 IPsec tunnels
2. Route propagation: Static routing vs BGP (dynamic)
3. NAT Gateway vs NAT Instance con VPN: NAT GW bloquea tráfico VPN; NAT Instance permite
4. VPN CloudHub: hub-and-spoke para múltiples sitios on-premises
5. Múltiples VPCs: VPN separada por VPC vs Shared Services VPC + VPC Peering

Puntos clave:
- Customer Gateway: dispositivo VPN on-prem con IP pública
- Virtual Private Gateway (VGW): adjunto a la VPC en AWS
- 2 túneles IPsec por redundancia
- Enrutamiento estático: editar tablas manualmente
- BGP (dinámico): tablas se actualizan solas, necesita ASN en ambos lados
- NAT Gateway NO permite tráfico desde VPN/Direct Connect hacia internet
- NAT Instance SÍ permite (más control de software)
- VPN CloudHub: hasta 10 Customer Gateways por VGW
- Múltiples VPCs: AWS recomienda VPN separada por VPC, o usar Shared Services VPC
