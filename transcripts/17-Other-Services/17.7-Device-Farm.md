# 17.7 - AWS Device Farm

## What is it
Application testing service for mobile and web apps on **real devices** (not emulators).

## Key Points
- Tests run on real browsers and real mobile devices
- Fully automated via testing frameworks
- If test fails → automatic videos + logs generated
- Remote login to devices for advanced debugging
- Supports: mobile apps (iOS/Android) and web apps

## Exam Tips
- "Test app on multiple real devices" → AWS Device Farm
- High level only — just know what it does
