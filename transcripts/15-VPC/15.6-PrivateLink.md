# 15.6 - AWS PrivateLink (VPC Endpoint Services)

## Key Concepts

1. PrivateLink: forma segura y escalable de exponer un servicio a miles de VPCs
2. Arquitectura: NLB (service VPC) + ENI (client VPC) + PrivateLink
3. PrivateLink para S3 via Direct Connect: Interface Endpoint + Private VIF
4. PrivateLink over VPC Peering: acceso cross-region a S3

Puntos clave:
- No requiere VPC Peering, Internet Gateway, NAT, ni Route Tables
- NLB en la VPC proveedora + ENI en la VPC cliente
- Si NLB está en múltiples AZ → ENIs también deben estar en múltiples AZ
- Gateway Endpoints solo funcionan desde dentro de la VPC (no desde on-premises via Direct Connect)
- Para Direct Connect → usar Interface Endpoint (PrivateLink) + Private VIF
- Para cross-region via VPC Peering → Interface Endpoint debe estar en la misma región que el bucket S3
