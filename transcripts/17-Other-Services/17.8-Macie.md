# 17.8 - Amazon Macie

## What is it
Fully managed data security and privacy service. Uses ML + pattern matching to detect sensitive data (PII) in S3 buckets.

## How it works
```
S3 Buckets → Macie (ML scan) → EventBridge → SNS / Lambda / etc.
```

- One-click activation, just specify which S3 buckets to scan
- Detects: PII (names, emails, credit cards, SSNs, etc.)
- Sends findings via EventBridge for downstream processing

## Exam Tips
- "Detect PII in S3" → Amazon Macie
- Output goes to EventBridge (not directly to SNS)
- ML-powered, fully managed, S3-focused
