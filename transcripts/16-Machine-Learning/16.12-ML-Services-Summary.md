# 16.12 - ML Services Summary

## Resumen para el examen

| Servicio | Para qué |
|----------|----------|
| Rekognition | Detección de caras, etiquetado, reconocimiento de famosos |
| Transcribe | Audio → Texto (subtítulos) |
| Polly | Texto → Audio (voz) |
| Translate | Traducciones de idioma |
| Lex | Chatbots / bots conversacionales |
| Lex + Connect | Centro de contacto en la nube |
| Comprehend | Procesamiento de lenguaje natural (NLP) |
| SageMaker | ML completo para devs y data scientists |
| Kendra | Motor de búsqueda de documentos con ML |
| Personalize | Recomendaciones personalizadas en tiempo real |
| Textract | Extraer texto y datos de documentos escaneados |
