# 17.6 - Amazon AppStream 2.0

## What is it
Desktop application streaming service. Stream a desktop app into a web browser — no infrastructure to buy or provision.

## AppStream 2.0 vs Workspaces

| | Workspaces | AppStream 2.0 |
|---|---|---|
| What | Full VDI desktop | Stream specific desktop apps |
| Access | VDI client or browser | Any web browser |
| Apps | Any app (native or WAM) | Specific apps streamed |
| Device | Any device with client | Any device with browser |
| Instance | Per workspace | Per application type (configurable CPU/RAM/GPU) |

## Key Points
- Each AppStream app runs on a configurable instance type (e.g. GPU instance for Photoshop/Blender)
- No need to connect to a full VDI — just stream the specific app
- Works cross-platform: run Windows app on Mac via Chrome

## Exam Tips
- "Stream specific app via browser" → AppStream 2.0
- "Full desktop / VDI" → Workspaces
- AppStream = app-level / Workspaces = desktop-level
