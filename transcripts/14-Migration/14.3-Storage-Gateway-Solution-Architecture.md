# 14.3 - Storage Gateway - Solution Architecture

## Transcript

### Arquitectura 1: File Gateway en VPC (EC2)
- File Gateway no solo corre on-prem, también puede correr en una VPC
- EC2 instances acceden al File Gateway via NFS/SMB
- Caso: EC2 accede a S3 como file system
- Caso: primer paso de migración on-prem → cloud (mismo protocolo NFS/SMB)

### Arquitectura 2: Procesamiento de datos en S3
- Una vez los datos están en S3, se abren posibilidades:
  - S3 Events → Lambda (procesar objetos)
  - Athena (queries SQL sobre S3, no afecta performance del gateway)
  - Redshift Spectrum o EMR (análisis)
  - Cross-Region Replication (DR en otra región)

### Arquitectura 3: Read-only replicas entre datacenters
- Datacenter A: File Gateway #1 (lectura/escritura) → S3
- Datacenter B: File Gateway #2 (solo lectura) ← S3
- Comparten el mismo bucket S3
- Los servidores en Datacenter B leen réplica con baja latencia

### Arquitectura 4: Lifecycle Policies para ahorro
- File Gateway → S3 Standard → S3 Standard-IA → S3 Glacier
- Políticas de ciclo de vida para mover datos fríos automáticamente
- NFS interface on-prem + cost savings en backend

### Arquitectura 5: S3 Versioning + RefreshCache API
- Habilitar S3 Object Versioning → múltiples versiones de archivos
- Restaurar archivo o file system completo a versión anterior
- IMPORTANTE: después de restaurar, llamar **RefreshCache API** en el gateway
- El gateway tiene caché, necesita saber que hubo cambios en S3

### Arquitectura 6: S3 Object Lock (WORM)
- File Gateway como sistema de archivos WORM (Write Once Read Many)
- Si alguien modifica/renombra un archivo → se crea nueva versión
- La versión original bloqueada NO se toca
- Para compliance, auditorías, protección contra borrado

---

## Key Concepts
- File Gateway puede correr en VPC (no solo on-prem)
- Datos en S3 = Lambda, Athena, Redshift Spectrum, EMR, CRR
- Read-only replicas entre datacenters via mismo bucket S3
- RefreshCache API para sincronizar gateway después de cambios en S3
- S3 Object Lock = WORM compliance en File Gateway
