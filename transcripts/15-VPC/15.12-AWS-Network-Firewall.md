# 15.12 - AWS Network Firewall

## Key Concepts

1. Network Firewall: protects entire VPC (Layer 3-7), managed by AWS
2. Internally uses Gateway Load Balancer (but AWS-managed)
3. Inspection VPC pattern: all traffic routed through Transit Gateway → Inspection VPC → destination
4. Rules: IP/port filtering, protocol blocking, domain filtering, regex patterns, IPS
5. Centrally managed via AWS Firewall Manager across accounts
6. Logs to S3, CloudWatch, Kinesis Data Firehose
