Las 3 categorías — ¿Cuándo usar cada una?

🍔 Pre-built
Tarea común (imágenes, audio, texto, traducción).
AWS entrenó el modelo. Vos llamás la API.
✓ Rápido, sin saber ML
✗ Solo lo que AWS ofrece
🧠 Bedrock
Modelos de fundación (Claude, Titan, Llama) via API.
Puede reemplazar la mayoría de pre-built + mucho más.
✓ Muy versátil, RAG, agentes
⚠ Poco en el examen (es nuevo)
👨‍🍳 SageMaker
Construís, entrenás y desplegás tu propio modelo con tus propios datos.
✓ Control total
✗ Necesitás saber ML
