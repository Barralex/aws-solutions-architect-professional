# 15.5 - VPC Endpoint Policies

## Key Concepts

1. VPC Endpoint Policy - JSON document to control access to a service
2. Additional layer of protection (doesn't replace IAM or resource policies)
3. S3 Bucket Policy + VPC Endpoint Policy combination
4. Conditions: aws:sourceVpce vs aws:sourceVpc vs aws:SourceIp
5. Troubleshooting checklist: EC2 private subnet → S3

## Raw Transcript

Bien, ahora hablemos de la seguridad de nuestros puntos finales de VPC. Y se denominan Políticas de puntos de conexión de VPC. Por lo tanto, la política de puntos de conexión de VPC, como puede adivinar, será un documento JSON para controlar el acceso a un servicio.

[...transcript completo pegado por usuario...]

La política de punto de enlace de VPC se aplica en el nivel de punto final de VPC. No anula ni reemplaza las políticas de IAM o las políticas de recursos.

aws:sourceVpce → un endpoint específico
aws:sourceVpc → toda la VPC (múltiples endpoints)
aws:SourceIp → solo IPs públicas

Troubleshooting EC2 private → S3:
1. Security Group (outbound rules)
2. VPC Endpoint Gateway + Endpoint Policy
3. Route Tables
4. VPC DNS resolution enabled
5. S3 Bucket Policy
6. IAM Role on EC2
