### Support Plans y Trusted Advisor

| Plan | Trusted Advisor | API Access |
|---|---|---|
| Basic | 7 checks básicos | NO |
| Developer | 7 checks básicos | NO |
| **Business** | **FULL checks** | **SÍ (AWS Support API)** |
| **Enterprise** | **FULL checks** | **SÍ (AWS Support API)** |

- Notificaciones semanales por email disponibles
- Business+ puede usar CloudWatch Alarms cuando se alcanzan límites

### Trampas del examen

1. **S3 Buckets:** Trusted Advisor detecta si el BUCKET es público, NO si los OBJETOS son públicos
   - Para objetos: EventBridge / S3 Events / AWS Config Rule

2. **Service Limits:** Trusted Advisor MONITOREA pero NO AUMENTA límites
   - Para aumentar: AWS Support Center (manual) o Service Quotas API (programático)

### Arquitectura: Monitoreo de Service Limits multi-account

```
Cuenta secundaria:
  Lambda (cron) → Refresh Trusted Advisor/Service Quotas
  → EventBridge (local) → EventBridge (central, cross-account)

Cuenta central:
  EventBridge central → SNS (email)
                       → SQS + Lambda + DynamoDB (resumen)
                       → Slack Notifier + Parameter Store (creds)

  Bonus: Lambda puede llamar Service Quotas API para aumentar límites automáticamente
```
