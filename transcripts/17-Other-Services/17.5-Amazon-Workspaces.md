# 17.5 - Amazon Workspaces

## What is it
Managed, secure cloud desktop (VDI - Virtual Desktop Infrastructure). Eliminates on-premises VDI management.
- Windows or Linux virtual desktop
- Pay per hour (on-demand) OR monthly subscription (unlimited use)
- Secure, encrypted, network isolation
- Integrated with Microsoft Active Directory

## Key Features

### WAM - Workspaces Application Manager
- Deploy and manage apps as virtualized application containers across all workspaces
- Different from Windows Updates: WAM = apps / Windows Update = OS

### Maintenance Windows (Windows Updates)
| Type | When updates run |
|------|-----------------|
| Always-on workspaces | Midnight–4am Sunday (default) |
| Auto-stopped workspaces | Started once/month automatically to install updates |
| Manual | You define the window |

### Cross-Region Redirection
- Primary region: AWS Managed Microsoft AD
- Failover region: **AD Connector** (Managed AD does NOT support cross-region)
- Connection aliases + Route 53 TXT record with Failover routing policy
- **WorkDocs** for user data persistence across regions (data is region-specific by default)

### IP Access Control Groups
- Like security groups for Workspaces
- IP/CIDR whitelist of allowed source IPs
- If users connect via VPN or NAT → must allow VPN/NAT public IP

## Exam Tips
- Cross-region failover → AD Connector (not Managed AD) in failover region
- User data persistence across regions → WorkDocs
- IP Access Control Groups = Workspaces security groups
- WAM = app deployment/management (not OS updates)
