# 17.10 - Amazon Pinpoint

## What is it
Scalable inbound/outbound marketing communication service.
Channels: email, SMS, push notifications, voice, in-app messages.
Scale: billions of messages/day.

## Key Use Cases
- Marketing campaigns (bulk email)
- Transactional SMS
- Segmented/personalized messaging

## Events Output
Text success, deliveries, replies → SNS / Kinesis Data Firehose / CloudWatch Logs

## Pinpoint vs SNS vs SES

| | SNS / SES | Pinpoint |
|---|---|---|
| Audience management | Your app manages it | Pinpoint manages it |
| Segmentation | Manual in your code | Built-in |
| Templates | Your app | Built-in |
| Campaigns | Your app | Built-in |
| Best for | Developers sending programmatic messages | Marketers running campaigns |

**Pinpoint = next evolution of SNS/SES for full marketing communication service**

## Exam Tips
- "Marketing campaigns + segmentation + templates" → Pinpoint
- "Simple programmatic email/SMS" → SES or SNS
- Pinpoint events → SNS / Firehose / CloudWatch
