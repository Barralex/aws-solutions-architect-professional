# 13.9 AWS Compute Optimizer

## Conceptos Clave

### Qué es
- Recomienda recursos óptimos para reducir costos y mejorar rendimiento
- Usa **Machine Learning** + métricas de CloudWatch
- Ahorro de hasta **~25%**
- Recomendaciones exportables a **S3**

### 4 recursos soportados
- EC2 Instances
- Auto Scaling Groups
- EBS Volumes
- Lambda Functions

### Métricas y CloudWatch Agent

| Métrica | Necesita CW Agent? |
|---|---|
| CPU, NetworkIn/Out, DiskIO | NO (built-in) |
| RAM / Memoria | SÍ (CloudWatch Agent) |

### Reglas para el examen
- "Right-sizing EC2/Lambda/EBS" → Compute Optimizer
- "Incluir RAM en recomendaciones" → necesita CloudWatch Agent
- NO soporta RDS, S3, DynamoDB, ECS
