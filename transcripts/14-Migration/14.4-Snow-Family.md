# 14.4 - Snow Family (Snowball)

## Transcript

### AWS Snowball
- Dispositivo físico, seguro y portátil
- Dos casos de uso: migración de datos + edge computing

### Dos tipos de Snowball Edge
1. **Edge Storage Optimized** - 210 TB de almacenamiento
2. **Edge Compute Optimized** - 28 TB de almacenamiento (más capacidad de cómputo)

### Caso de uso 1: Migración de datos
- 100 TB a 1 Gbps = 12 días por red
- Problemas: conectividad limitada, ancho de banda limitado, costo de red alto, conexión inestable
- Regla: si tarda más de 1 semana por red → usar Snowball
- Proceso: AWS envía dispositivo → lo cargás con datos → lo enviás de vuelta → datos van a S3

### Caso de uso 2: Edge Computing
- Procesar datos donde se crean: camión, barco, mina
- Lugares con Internet limitado o sin Internet
- Snowball Edge Compute Optimized para este caso
- Puede ejecutar instancias EC2 y funciones Lambda en el dispositivo
- Casos: preprocesar datos, ML en el edge, transcodificar media

---

## Key Concepts
- Snowball = dispositivo físico para mover petabytes o computar en el edge
- Storage Optimized (210 TB) vs Compute Optimized (28 TB)
- Regla: >1 semana de transferencia por red → Snowball
- Edge computing: EC2 + Lambda en el dispositivo
