# 14.5 - Snow Family - Solution Architecture (Performance)

## Transcript

### Mejorar rendimiento de transferencia en Snow Family
Recomendaciones de AWS (de mayor a menor impacto):

1. **Múltiples operaciones de escritura a la vez** - desde múltiples terminales
2. **Batch de archivos pequeños** - agrupar en zip (mínimo 1MB) antes de cargar
3. **No operar archivos durante transferencia** - no tocar los archivos mientras se transfieren
4. **Reducir uso de red local** - eliminar saltos innecesarios, conectar dispositivo directo a la computadora
5. **Interfaz de archivos:** 25-40 MB/s típico
6. **Amazon S3 Adapter for Snowball:** 250-400 MB/s (10x más rápido)

---

## Key Concepts
- Múltiples escrituras simultáneas = mayor impacto
- Batch archivos pequeños en zips ≥ 1MB
- S3 Adapter for Snowball = 250-400 MB/s vs 25-40 MB/s interfaz normal
