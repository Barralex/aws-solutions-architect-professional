# 16.10 - Amazon Personalize Overview

## Key Concepts

1. Servicio de ML totalmente gestionado para recomendaciones personalizadas en tiempo real
2. Misma tecnología que usa Amazon.com para recomendar productos
3. Datos de entrada: S3 (historial de usuarios) + API en tiempo real
4. Expone una API personalizada para web, apps móviles, SMS, email
5. Construir el modelo lleva días, no meses — no necesitás saber ML
6. Casos de uso: e-commerce, medios, entretenimiento
7. Exam tip: "recomendaciones personalizadas" → Amazon Personalize
