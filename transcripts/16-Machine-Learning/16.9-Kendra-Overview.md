# 16.9 - Amazon Kendra Overview

## Key Concepts

1. Servicio de búsqueda de documentos totalmente gestionado con ML
2. Fuentes: texto, PDF, HTML, PowerPoint, Word, FAQs, etc.
3. Kendra indexa todos los documentos → construye un índice de conocimiento con ML
4. Búsqueda en lenguaje natural (como Google): "¿Dónde está el soporte informático?" → "1ª planta"
5. Aprendizaje incremental: aprende de interacciones y feedback del usuario
6. Permite afinar resultados: por fecha, relevancia, filtros personalizados
7. Exam tip: "búsqueda de documentos" → Amazon Kendra
