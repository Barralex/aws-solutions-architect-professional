All AWS Firewall Services — When to use what

Don't confuse them on the exam. Each has a specific scope.

ServiceScopeWhat it does
NACL Subnet level Basic allow/deny by IP & port · stateless · rule order matters
Security Group Instance level Allow rules only · stateful · remembers connections
AWS WAF HTTP layer (L7) Protects ALB, CloudFront, API GW · SQL injection, XSS, rate limiting
AWS Shield DDoS protection Standard (free, auto) · Advanced (paid, 24/7 response team)
Network Firewall Entire VPC (L3-L7) Full inspection · IPS · domain filtering · regex · 10K+ rules
Firewall Manager Multi-account Centrally manages rules for WAF, Shield, SG, Network Firewall
⚠️ Exam key:
• "Block malicious IP" → NACL (has Deny)
• "Protect against SQL injection on ALB" → WAF
• "Inspect all VPC traffic, IPS, domain filtering" → Network Firewall
• "Manage firewall rules across all accounts" → Firewall Manager
