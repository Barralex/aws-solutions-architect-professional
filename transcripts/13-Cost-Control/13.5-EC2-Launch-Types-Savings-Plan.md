# 13.5 EC2 Launch Types & Savings Plan

## EC2 Launch Types

| Tipo | Duración | Descuento | Riesgo | Caso de uso |
|---|---|---|---|---|
| On-Demand | corta | 0% | ninguno | Default, predecible |
| Spot | corta | ~90% | ALTO (te la quitan) | Fault-tolerant, batch, CI/CD |
| Reserved | 1-3 años | ~72% | ninguno | Workloads estables |
| Convertible Reserved | 1-3 años | ~66% | ninguno | Estable pero flexible tipo |
| Dedicated Instance | variable | variable | ninguno | No compartir hardware |
| Dedicated Host | variable | variable | ninguno | Licencias core/socket, host affinity |

### Dedicated Instance vs Dedicated Host
- **Dedicated Instance:** hardware exclusivo, pero no ves/controlás el servidor
- **Dedicated Host:** ves cores/sockets, controlás placement, host affinity
- Licencias por core/socket → **Dedicated Host**

## Savings Plans

Te comprometés a gastar $X/hora por 1-3 años. Lo que exceda = On-Demand.

| Tipo | Descuento | Locked | Flexible |
|---|---|---|---|
| EC2 Instance | ~72% | Familia + Región | Tamaño, OS, Tenancy |
| Compute | ~66% | Nada | Familia, Región, Compute type (EC2/Fargate/Lambda), OS |
| SageMaker | ~64% | - | ML workloads |

### Regla: más descuento = menos flexibilidad
- Siempre M5 en us-east-1 → EC2 Instance Savings Plan (72%)
- Migrando entre EC2/Fargate/Lambda → Compute Savings Plan (66%)
