# 17.11 - EC2 Image Builder

## What is it
Automate creation, maintenance, validation, and testing of EC2 AMIs (and container images).
**Free service** — pay only for underlying EC2 instances used during build.

## How it works
```
EC2 Image Builder
→ Creates base EC2 instance
→ Runs Build Components (installs/configures software)
→ Creates AMI
→ Launches new EC2 from AMI for testing
→ Distributes AMI to regions/accounts
```

- Runs on schedule (weekly, on package updates, etc.)
- Can publish AMI to multiple regions AND multiple accounts

## CI/CD Architecture
```
CodeCommit → CodeBuild → CloudFormation → EC2 Image Builder → CloudFormation
(source)     (compile)   (trigger builder) (creates AMI)      (rolling update on ASG)
                                                               old AMI → new AMI
```

All orchestrated by **CodePipeline**.

## Exam Tips
- EC2 Image Builder = automate AMI creation + testing + distribution
- Free service (pay for EC2 instances only)
- CI/CD pattern: CodePipeline + CodeBuild + Image Builder + CloudFormation rolling update on ASG
- Can distribute to multiple regions and accounts
