# 16.5 - Amazon Lex + Amazon Connect

## Key Concepts

1. Lex: same tech as Alexa — ASR + NLU (understands intent from speech/text) → chatbots, call center bots
2. Connect: cloud-based contact center — receive calls, create contact flows, 80% cheaper than traditional
3. Flow: Phone call → Connect → Lex (understands intent) → Lambda (takes action) → CRM
