# 13.4 AWS Service Quotas

## Conceptos Clave

### Qué es
- Servicio para **monitorear y gestionar límites** de todos los servicios AWS
- Notifica cuando estás cerca de un umbral
- Puede crear **CloudWatch Alarms** directamente desde la consola
- Disponible para **todos los planes** (no requiere Business como Trusted Advisor)

### Funciona para todos los servicios
- Lambda (concurrent executions)
- EC2 (vCPUs por región)
- VPC (VPCs por región)
- EBS, S3, RDS, ELB, CloudFormation, etc.

### Service Quotas vs Trusted Advisor

| Capacidad | Trusted Advisor | Service Quotas |
|---|---|---|
| Monitorear limits | ✅ | ✅ |
| Aumentar limits | ❌ | ✅ (API) |
| Crear CloudWatch Alarms | ❌ | ✅ |
| Requiere Business+ plan | ✅ | ❌ |

### Regla para el examen
- "Monitorear límites + alarma" → Service Quotas + CloudWatch Alarm
- "Aumentar límites programáticamente" → Service Quotas API
