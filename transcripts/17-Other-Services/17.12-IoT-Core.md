# 17.12 - AWS IoT Core

## What is it
Connect IoT devices to the cloud securely and at scale. Serverless, handles billions of devices and trillions of messages.

## How it works
```
IoT Devices → MQTT protocol → IoT Topic → IoT Rules → Actions → AWS Services
```

- IoT Topics = like SNS topics (pub/sub)
- MQTT = lightweight messaging protocol for IoT devices
- IoT Rules = define what to do with incoming messages
- Actions = send to AWS services

## Integrations (Actions)
Kinesis, DynamoDB, SQS, MSK, SNS, S3, Lambda, and more.

## Key Integration: IoT Core + Kinesis Firehose
```
IoT Devices → MQTT → IoT Core → Kinesis Firehose → Lambda (transform) → S3 / Redshift / OpenSearch
```

## Exam Tips
- "Connect IoT devices to cloud" → AWS IoT Core
- Protocol: MQTT
- IoT Rules → Actions → AWS services
- Key pipeline: IoT Core → Firehose → S3/Redshift/OpenSearch
