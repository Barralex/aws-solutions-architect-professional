# 14.9 - AWS FIS (Fault Injection Simulator)

## Transcript

### Qué es FIS
- Ejecutar experimentos de inyección de fallas en cargas de trabajo AWS
- Basado en Chaos Engineering (crear eventos disruptivos para probar resiliencia)
- Descubrir bugs ocultos y cuellos de botella de performance

### Servicios soportados
- EC2 (terminar instancias)
- ECS (detener tareas)
- EKS (detener tareas Kubernetes)
- RDS (forzar failover)

### Cómo funciona
1. Crear experimentos (plantillas prediseñadas)
2. Elegir disrupciones: CPU spike, memoria, DB failover, terminar instancias
3. Ejecutar el experimento
4. Monitorear con CloudWatch, EventBridge, X-Ray
5. Detener y analizar resultados

---

## Key Concepts
- FIS = Chaos Engineering nativo de AWS
- Inyecta fallas controladas para probar resiliencia
- "Chaos engineering" o "fault injection" en examen → FIS
